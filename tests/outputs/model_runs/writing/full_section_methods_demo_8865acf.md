The method is organized around resolving insertion-pose uncertainty before guarded contact execution. In contact-rich peg insertion under partial visual occlusion, the controller should not commit to contact from an ambiguous pose estimate when additional visual evidence can still refine the target. The reader path therefore starts from overhead and side RGB-D observations, a candidate insertion pose, and a confidence estimate. These inputs define a pose-estimation stage whose role is to produce a contact-ready estimate before the insertion controller takes over.

The intermediate object passed through the method is an insertion pose estimate paired with confidence. The confidence value determines whether the current visual evidence is sufficient for execution or whether the system should request an additional view. When confidence is low, the new observation is used to update the insertion pose rather than to create a separate downstream decision. This keeps the representation compact: the controller receives a refined pose estimate, while the perception side remains responsible for deciding whether the estimate has enough visual support.

Execution begins only after the refined pose estimate has been handed to the guarded insertion controller. The controller executes insertion from that pose and monitors the action through force and pose-deviation limits. If either limit is reached, execution stops instead of continuing contact from an uncertain or inconsistent state. This design separates pose refinement from guarded execution: the visual stages reduce insertion-pose uncertainty before contact, while the controller enforces the local stopping condition during insertion.
