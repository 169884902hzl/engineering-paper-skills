Given synchronized overhead and side RGB-D observations, the system first estimates an insertion pose together with a confidence score, rather than sending the observations directly to control. This intermediate state is the main handoff object: when the confidence is sufficient, it defines the pose used for insertion, and when confidence falls below its decision threshold, it triggers acquisition of an additional view before the motion continues. The new view is used to refine the insertion pose estimate, so the control stage receives an updated geometric target instead of an unrecovered ambiguous observation. This ordering is used because visual uncertainty that is left unresolved before contact can propagate into the peg-hole interaction and become difficult to correct once the peg begins entering the hole. The guarded insertion controller then executes from the current pose estimate while monitoring measured force and pose deviation, stopping when either exceeds its specified limit. The method therefore maps multi-view observations to pose, confidence, guarded execution, and finally a binary success or failure outcome with an associated failure reason.
