Small-part insertion is difficult because the visual estimate used to begin execution can degrade precisely as the robot approaches contact. With fixed cameras, the target may be visible during early approach but become hidden in the near-contact region, leaving the controller to execute from a pose estimate that is no longer well supported by current observations. This weakens the common assumption that the target pose is already reliable before insertion begins. We study a confidence-triggered viewing strategy that acquires an additional view when the current estimate is insufficient, then passes the updated pose to guarded insertion. In a one-arm, one-fixture evaluation on a single peg family, the method reaches 84% success over 180 trials, compared with 69% for a fixed overhead view, 72% for a fixed side view, and 61% for open-loop execution.
