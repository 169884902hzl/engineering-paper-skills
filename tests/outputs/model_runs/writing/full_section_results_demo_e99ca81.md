The full system reached 84% success over 180 contact-rich peg insertion trials under partial visual occlusion, outperforming fixed overhead sensing at 69%, fixed side sensing at 72%, and open-loop execution at 61%. The view-specific comparisons show complementary failure modes: the overhead view tends to lose the hole near final approach, while the side view preserves lateral visibility but leaves depth uncertain. Open-loop execution performs worst because pose error is carried into contact rather than corrected during the task.

The additive ablation clarifies how the main components contribute. A naive direct action hint achieved 17% success, and adding geometry-aware execution raised this to 23%. Combining target-focused perception with geometry-aware execution increased success to 44%, indicating that action structure alone is insufficient when the target remains weakly localized. Adding overlay self-verification raised performance to 76%, while the full mask-constrained grounding variant reached 88%. These rows are additive rather than factorial, so the ablation supports the value of the staged system design but does not isolate all component interactions.

The remaining failures occur when all available views are ambiguous or when contact produces a large pose deviation. The results therefore characterize performance within a single tabletop fixture using one 7-DoF robot arm and one cylindrical peg family. They do not establish confidence intervals, statistical significance, cross-robot transfer, or deployment-scale robustness.
