In the ablation, the main bottleneck is not simply executing an action once an insertion hint is produced, but grounding that hint to the correct visually ambiguous target. A naive direct action hint reaches only 17% success, and adding geometry-aware execution raises success to 23%, indicating that better action realization alone provides limited benefit when target selection remains uncertain. Adding target-focused perception increases success to 44%, showing that reducing scene-level ambiguity is a necessary step before execution can be reliable. The largest gain enters when overlay self-verification is added, raising success from 44% to 76%; this stage rejects action hints that are visually plausible but poorly grounded, making it the dominant contribution in the staged pipeline. The full system further reaches 88% with mask-constrained grounding, which reduces residual spatial ambiguity near the target. Since these are additive rows over one task family rather than isolated component swaps, the ablation supports a contribution-level interpretation of where each stage enters the pipeline.
