Robot shelf picking of transparent cups exposes a perception failure that is easy to miss in a single-view pipeline: the rim or edge that supports a grasp hypothesis can be visible from one viewpoint and nearly vanish from another. This view-dependent evidence makes a fixed single-image grasp decision brittle when the first observation has low confidence. We therefore frame the problem as selective active perception for shelf picking: the robot requests a second view only when the initial estimate is uncertain, using the extra observation to check whether the cup edge remains consistent before committing to a grasp. This formulation targets fewer poorly supported grasps in constrained lab-bin settings, rather than claiming warehouse-scale generality.

A stronger claim would need warehouse or shelf-scale trials, quantitative grasp-failure comparisons, and evidence that the second-view trigger improves decisions across more object layouts and viewing angles.
