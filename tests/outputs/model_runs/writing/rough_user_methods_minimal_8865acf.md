The Methods overview follows the information path from visual evidence to execution. The system observes the insertion scene with overhead and side RGB-D views, then estimates both the insertion pose and a confidence value for that estimate. When the pose estimate has low confidence, the system requests one additional view and updates the pose before execution, so the controller receives a refined target rather than acting on the initial observation alone. The updated pose is then passed to a guarded insertion controller, which executes the insertion while monitoring force and pose deviation. Execution stops when either force feedback or pose deviation exceeds the allowed operating condition. This overview defines the main method flow, but does not specify formulas, numerical thresholds, latency, calibration procedures, or pseudocode.
