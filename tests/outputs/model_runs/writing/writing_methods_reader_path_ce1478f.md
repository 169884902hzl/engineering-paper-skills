The method takes overhead and side RGB-D observations as input and maintains an insertion pose estimate together with a confidence score. When the confidence is low, the system requests an additional view before passing the current estimate to a guarded insertion controller. The controller attempts insertion under explicit stop conditions, terminating when the force threshold is exceeded or when pose deviation exceeds its allowed limit. The procedure outputs a binary insertion status, reporting success or failure without assuming a particular confidence formula, threshold value, calibration procedure, timing profile, or pseudocode implementation.
