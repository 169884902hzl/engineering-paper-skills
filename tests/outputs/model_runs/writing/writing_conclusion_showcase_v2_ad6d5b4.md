This work presented a confidence-triggered multi-view insertion system for contact-rich peg insertion under partial visual occlusion. The system estimates insertion pose and confidence from overhead and side RGB-D observations, requests another view when confidence is low, refines the pose estimate, and executes the insertion with force and pose-deviation stops. Across 180 trials in the evaluated tabletop setup, the full system reached 84% success, compared with 69% for a fixed overhead camera, 72% for a fixed side camera, and 61% for an open-loop controller. These results support the system-level takeaway that confidence-aware visual refinement and guarded contact execution can improve insertion reliability in occluded settings where a single fixed view or open-loop motion leaves more failures unresolved.

The operating scope of the study is a single 7-DoF arm, one tabletop fixture, and one cylindrical peg family, without statistical significance testing, cross-robot evaluation, deployment evaluation, or an isolated causal separation between view selection and guarded execution. The remaining failures make the next technical targets specific: cases in which all available views remain ambiguous require better ways to acquire or judge visual evidence before committing to insertion, while contact events that create large pose deviation require more capable guarded execution. Future work should expand the method along these two failure regimes before testing whether the same system design transfers to broader hardware, fixtures, and peg geometries.
