The discussion should treat the 84% full-system success rate as evidence for the value of viewpoint updating, not as a deployment-level reliability claim. Across 180 trials, the full system outperforms fixed overhead view (69%), fixed side view (72%), and open-loop execution (61%), indicating that refreshing the observation geometry helps the system recover task-relevant pose information before execution becomes difficult to correct. The remaining failures, however, identify the present operating boundary: the system still fails when none of the available viewpoints resolves the target clearly, or when post-contact pose deviation exceeds the guarded recovery range. This boundary is also shaped by the evaluation scope, which covers one 7-DoF robot arm, one fixture, and one cylindrical peg family, without significance testing, cross-robot validation, or industrial deployment evidence. The next experimental step should therefore expand fixture and peg-family diversity before making broader claims, and pair that expansion with statistical tests and a finer failure breakdown to separate perception-limited cases from contact-recovery-limited cases.
