We presented a confidence-triggered multi-view insertion system for contact-rich peg insertion under partial visual occlusion. The system estimates insertion pose and confidence from overhead and side RGB-D observations, requests another view when confidence is low, refines the pose estimate, and executes with force and pose-deviation stops. Across 180 trials, the complete system achieved 84% success, compared with 69% for a fixed overhead camera, 72% for a fixed side camera, and 61% for an open-loop controller. This result supports the system-level contribution: using confidence to trigger additional visual evidence before guarded execution improves the evaluated insertion pipeline in this occluded tabletop setting, while the study does not separate the individual causal roles of view selection and guarded execution.

The demonstrated operating envelope is a single-arm tabletop insertion setting for one cylindrical peg family, where overhead and side RGB-D observations usually provide enough evidence to refine the insertion pose before contact-rich execution. Failures remain concentrated in cases where all available views are ambiguous or where contact produces large pose deviation, defining the main boundary of the current system. Future work should therefore focus on detecting and recovering from persistent visual ambiguity and contact-induced pose change, followed by evaluations across additional fixtures, peg families, and robot platforms with statistical testing.
