# Error Archive

Use this to diagnose recurring manuscript failure symptoms.

## Methods as Directory

Symptom: overview announces modules but does not define the system.

Fix:

- rewrite first paragraph as roles, inputs, outputs, component order
- explain why the main object/signal appears first

## Experiments as Table Narration

Symptom: text reports pooled averages but does not explain what they prove.

Fix:

- add overall interpretation
- split meaningful task/object/condition axes
- add failure envelope

## Overstrong Causality

Symptom: text uses `stems from`, `proves`, or `confirms` when mechanism is not
directly measured.

Fix:

- downgrade to `is consistent with`, `suggests`, or `indicates`
- move unsupported mechanism to bounded interpretation

## AI-Looking Prose

Symptom:

- repeated transitions
- symmetric three-part clauses
- vague pronouns
- unsupported adjectives

Fix:

- concrete nouns
- varied sentence relations
- explicit referents
- claim-evidence-boundary pattern

## Figure or Caption Overreach

Symptom: caption claims a mechanism the visual does not show.

Fix:

- define visual responsibility
- caption visible content and reading order only
- move interpretation to Results if evidence supports it

## Related Work as Citation Stream

Symptom: paper-by-paper list with no axis or nearest-neighbor distinction.

Fix:

- group by technical axis
- end each axis with a limitation
- isolate nearest-neighbor difference

## Conclusion Revives Removed Claims

Symptom: conclusion introduces new results, terms, or deleted analysis.

Fix:

- paragraph 1: method + strongest evidence
- paragraph 2: boundary + direct future work
