# Claim-Strength Diff

Use this before accepting polished prose. Polishing must not make the claim
stronger unless the user supplied stronger evidence.

```text
Claim-strength diff
| Source claim | Revised claim | Strength change | Evidence added? | Allowed? | Repair |
```

## Strength Ladder

`observes < suggests < supports < shows < demonstrates < establishes < proves`

Move down the ladder when evidence is local, incomplete, qualitative, or lacks
ablation/stress testing. Move up only when the user provides direct support.
