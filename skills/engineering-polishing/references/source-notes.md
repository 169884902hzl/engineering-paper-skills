# Source Notes To English Prose

Use this when rough notes, non-English notes, or internal shorthand must become
English manuscript prose.

## Rule

Translate meaning, not confidence. Do not turn guesses or shorthand into
published facts.

## Triage Table

| Source item | Type | Can enter prose? | Safe handling |
|---|---|---|---|
| measured result | fact | yes | preserve number, metric, condition |
| method step | fact if implemented | yes if provided | keep terminology stable |
| likely explanation | assumption | only with hedge | mark as interpretation |
| desired claim | unsupported | no | list as evidence needed |
| citation hint | source needed | no unless verified | use citation placeholder |

## Default Output

```text
Facts
- ...

Assumptions
- ...

Unsupported claims
- ...

English prose
[bounded paragraph]
```
