# Rebuttal Versus Revision Mode

Use this before drafting response text.

| Mode | Allowed output | Forbidden output |
|---|---|---|
| Rebuttal | correct factual misunderstandings and point to existing evidence | claim new experiments or edits |
| Revision response | map completed changes to manuscript locations | claim unverified line numbers |
| Camera-ready note | describe final minor fixes | reopen major unsupported claims |
| Internal plan | assign tasks and missing inputs | write final editor-facing prose |

When the mode is unclear, output a plan and missing inputs before a final
response letter.
