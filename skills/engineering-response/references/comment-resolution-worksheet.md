# Comment Resolution Worksheet

Use this before editing after advisor, senior-author, reviewer, or editor
comments.

## Step 1: Comment Intake

Split comments into one row each.

| Original quote | Type | Severity | Target section | Must handle now? |
|---|---|---|---|---|

Severity:

- `must fix`: blocks clarity, evidence, correctness, or submission
- `should fix`: improves paper but has manageable risk
- `optional`: useful only if time/page budget allows

## Step 2: Root Cause and Target

For each comment:

```text
The issue is not [surface complaint]; it is that [section job or evidence chain]
is not established.
```

Then choose only one to three targets. Do not write `polish whole section`.

## Step 3: Minimal Fix Decision

| Comment | Decision | Reason | Prohibited over-edit |
|---|---|---|---|

Prohibited over-edit is mandatory. It prevents a comment about evidence from
turning into an unnecessary Methods rewrite, or a comment about positioning from
turning into sentence-level polishing only.

## Step 4: Acceptance and Verification

| Comment | Acceptance evidence | Minimum verification |
|---|---|---|

Acceptance evidence should be observable:

- revised paragraph now contains data -> interpretation -> boundary
- setup prose moved into a table
- Methods overview states roles and component order
- contribution maps to both mechanism and experiment
- caption no longer claims invisible mechanisms

If verification cannot be specified, the task is not ready to edit.
