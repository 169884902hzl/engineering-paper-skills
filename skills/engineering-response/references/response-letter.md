# Response Letter

Use this for English point-by-point replies.

## Response Anatomy

For each comment:

1. preserve or quote the reviewer concern
2. acknowledge the issue
3. state what was changed or why no change was made
4. map to manuscript location or placeholder
5. explain scientific reasoning when needed

## Template

```text
Comment R1.2:
[Reviewer comment]

Response:
We thank the reviewer for pointing out [concern]. We have revised [section] to
[specific action]. The revised text now [what it clarifies], and the change is
reflected in [location]. [If needed: We did not perform X because ..., and we now
state this limitation in ...].
```

## Do Not Claim

- line numbers not supplied or verified
- experiments not performed
- figures not changed
- citations not added
- statistical tests not run

Use placeholders when author input is missing:

```text
[AUTHOR_INPUT_NEEDED: confirm line numbers after final compile]
```
