# Venue Figure Standards

Use this when the user names a target venue or asks for top-tier figure quality.

## Checklist

| Check | Requirement |
|---|---|
| Standalone clarity | figure plus caption should reveal the evidence role |
| Claim boundary | caption states visible/tabulated facts, not hidden mechanisms |
| Source traceability | plotted values and statistics can be traced to source data |
| Panel hierarchy | most important evidence is visually primary |
| Export readiness | format, text editability, resolution, and labels match venue needs |
| Integrity | no image or axis manipulation hides uncertainty or failure |
