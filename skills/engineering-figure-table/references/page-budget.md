# Visual Page Budget

Use this when the paper is over page budget.

## Cut Order

1. compress setup prose into a table
2. remove caption repetition
3. reduce figure whitespace
4. tighten table notes without losing definitions
5. shorten prose around main results
6. only then consider removing a visual

## Protect

- main results evidence
- ablation evidence
- failure or boundary evidence
- framework visual if it is the only system overview
- caption definitions needed to understand categories or metrics

Do not cut evenly across all sections. Cut repetition and setup compression
first, while protecting formulation, main results, ablations, and failure
boundaries.

## Dangerous Cuts

- shrinking a figure until labels cannot be read
- deleting category analysis while keeping only pooled averages
- removing ablation interpretation
- shortening captions until panel meanings become unclear
- changing category names in one location only

## Post-Cut Check

After each cut, verify:

- the figure/table still has one responsibility
- main result evidence remains interpretable
- ablation evidence still maps to contributions
- category names remain consistent
- caption still explains what the reader sees
