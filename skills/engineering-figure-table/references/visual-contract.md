# Visual Contract

Use this before changing any figure or table.

## Contract Fields

| Field | Question |
|---|---|
| Claim | What manuscript claim does this visual support? |
| Reader action | What should the reader learn or compare? |
| Evidence | Which data, example, sequence, or setup fact is shown? |
| Boundary | What must the visual not claim? |
| Text relation | Does the prose explain the evidence or merely repeat the visual? |

## Common Visual Roles

- motivation figure: show why an old route fails
- framework figure: show system roles and information flow
- workflow montage: show observable sequence and handoff
- setup table: compress shared protocol and constants
- main results table: support core outcome and category axes
- ablation table: map components to contributions
- stress-test table/plot: define boundary or sensitivity

## Red Flags

- caption tries to prove hidden theory
- main result table has no prose interpretation
- ablation table lists components but not contribution roles
- setup section is longer than results because details were not moved into a
  table
- figure is visually dense but has no reading order
