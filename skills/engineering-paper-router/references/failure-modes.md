# Engineering Paper Router Failure Modes

## Writing Instead Of Routing

Risk: the router starts drafting prose before the correct skill is selected.

Response: output the route, missing inputs, and next prompt only.

## Single-Skill Bias

Risk: a mixed task is forced into one skill.

Response: name primary and secondary skills, then order the workflow.

## Missing Evidence Boundary

Risk: the user asks for a strong result or readiness claim during routing.

Response: preserve evidence-bound warnings in the next prompt.
