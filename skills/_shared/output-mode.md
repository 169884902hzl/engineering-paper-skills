# Shared Output Mode

If the user explicitly asks for output only, provide the requested prose, table,
caption, response, or validation summary only when doing so does not hide a
claim/evidence problem.

Always include a minimal note when any of these are true:

- the requested text would include unsupported claims
- the task asks for invented evidence, citations, or line numbers
- readiness or completion cannot be verified
- non-English source notes contain assumptions or guesses

Minimal note format:

```text
Unsupported / not verified:
- ...
```
