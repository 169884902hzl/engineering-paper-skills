This project should improve discovery through useful public content, not
keyword stuffing.

- GitHub repository About description.

## Launch Note Guidance

Write a technical launch note only after the README and demo gallery reflect the
current evidence boundary.

Safe claims:

- Evidence-bound Codex skills for engineering paper writing and manuscript
  audit.
- Beta skill suite for robotics, ML, systems, and experiment-heavy papers.
- Includes demo outputs, local model-run artifacts, structured expected
  behavior specs, and quality checks.

Do not claim:

- top-tier ready
- submission ready
- citation verified
- official venue compliant
- professor-level review proven
- CI-proven behavior unless a real behavior regression artifact is linked

Recommended channels:

- GitHub repository README and Pages.
- GitHub profile or pinned repository.
- A technical blog post or Zhihu article with one concrete full-paper audit
  example.
- Targeted discussion with research-writing or robotics/ML communities.
