How To Get Strong Prose

  • Give the section target and ask for manuscript prose first.
  • Name the task bottleneck and method object.
  • Provide a result table plus diagnostic axes or failure modes.
  • State the boundary and forbidden claims before the draft request.

Safety / audit examples

Safety And Audit Examples are for checking claim strength, figure/table support, response truthfulness, and readiness. They are separate from the writing gallery.

Conservative Claim Audit

Input:
Evidence: 84% success over 180 trials, one robot,
one tabletop fixture, one object family.

Draft:
The system is deployment-ready and proven robust
for industrial insertion.
Illustrative audit:
Diagnosis: not ready as written.

Safe rewrite:
In the evaluated tabletop insertion setup, the
system achieved 84% success over 180 trials on one
robot arm and one object family. Broader industrial
deployment remains untested.

Reviewer Response Truthfulness

Input:
Reviewer asks for stress-test evidence.

Draft response says:
We added Table 3, new stress tests, and final line
numbers.
Illustrative audit:
Package status: revision plan only.
The draft response cannot claim added experiments,
tables, or final line numbers unless those changes
are present in the revised manuscript package.

Mini Walkthrough

Rough evidence:
Method: multi-view RGB-D insertion with guarded
execution.
Results: 84% over 180 trials.
Boundary: one robot, one fixture, one object family.

Safe manuscript sentence:
In the evaluated tabletop setup, the system achieved
84% success over 180 trials and improved over the
fixed-view and open-loop baselines.
