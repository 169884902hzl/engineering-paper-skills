# 零基础上手：用 engineering-paper-coach 写工程论文

这份说明写给第一次写论文、不知道从哪开始的人。你只需要说一句话，coach
会先看你手上已经有什么，判断你走到了哪个阶段，然后每一轮给你一个具体的产出，
并告诉你下一步做什么、需要准备什么。

它不会替你编实验、编数据、编引用。没做的实验会标成"还缺"，不会写成"已完成"。

## 1. 安装（只做一次）

先把仓库下载到本地：

```bash
git clone https://github.com/169884902hzl/engineering-paper-skills.git
cd engineering-paper-skills
```

如果你用 Codex：

```bash
cp -a skills/_shared skills/engineering-* ~/.codex/skills/
```

如果你用 Claude Code：

```bash
cp -a skills/_shared skills/engineering-* ~/.claude/skills/
```

拷完后重启 Codex 或 Claude Code。

- `_shared` 文件夹一定要一起拷，coach 会用到里面的经验文件。
- 如果提示目录不存在，先运行 `mkdir -p ~/.codex/skills`（Claude Code 换成
  `~/.claude/skills`）。
- 更新和卸载方法见 README 的 [Installation](../README.md#installation) 一节。

## 2. 第一句话怎么说

在 Codex 里用 `$engineering-paper-coach` 开头；在 Claude Code 里说
"用 engineering-paper-coach skill"，后面接你的情况。中文、英文都可以。

**例 1：只有一个想法**

```text
$engineering-paper-coach 我想写一篇论文。机械臂插孔时相机常被遮挡，
我打算在置信度低的时候让机器人换个视角再看。还没做实验，不知道从哪开始。
```

你会拿到一句话贡献：任务是什么、现有方法在哪里不行、你的方法、还需要什么证据、
适用范围。空着的地方标 `[?]`，最后最多问你 3 个问题。

**例 2：已经有实验数据**

```text
$engineering-paper-coach 帮我看看这篇论文该怎么写。项目在 ~/my-project，
结果是 results/ 里的 CSV，笔记在 notes.md。
```

它会先读你的文件（只读，不改文件、不跑实验），告诉你读了哪些文件、判断你在哪个
阶段，再给出结果表骨架或论文提纲。

**例 3：已经有初稿**

```text
$engineering-paper-coach 初稿写完了，在 paper/main.tex。请一步步带我改：先看审稿人会
挑什么毛病，再告诉我下一步。
```

第一轮你会拿到模拟审稿人最可能提的三条意见和各自最省事的修法；之后几轮依次是
LaTeX 一致性检查和按顺序修改。

如果你只想做一件具体的事（比如润色一段话），直接说就行，coach 会直接给结果，
不走引导流程。

## 3. 每个阶段你会得到什么

| 你手上有什么 | 阶段 | 这一阶段会依次得到 |
|---|---|---|
| 只有想法 | S0 | 一句话贡献：任务、现有方法的不足、你的方法、还需要的证据、适用范围 |
| 实验在计划或正在跑 | S1 | 结果表骨架（行是你的方法和对照组，列是测试条件或类别）、还缺的实验清单、实验 pre-mortem（提前设想实验或论文可能怎么失败，趁还来得及补救） |
| 已经有结果 | S2 | 带页数分配的提纲、图表计划，然后按 方法、实验、引言、摘要 的顺序逐节写 |
| 有完整初稿 | S3 | 模拟审稿、LaTeX 一致性检查、先改论证再改措辞的修改建议 |
| 收到审稿意见 | S4 | 逐条修改计划和回复信 |

摘要放在最后写，是因为它只能承诺正文已经撑得住的内容。

每一轮回复最后都有三行：本轮产出、下一步、请准备。照着"请准备"把材料带来，
下一轮就能接着往下走。

## 4. 常见问题

**我完全不懂这些术语怎么办？**
coach 第一次用到术语时会用大白话解释，比如"baseline（你拿来比较的方法）"。
没看懂就直接问。

**它会不会帮我编数据或引用？**
不会。没有的结果标 `[RESULT NEEDED]`，没给出处的引用标 `[CITATION NEEDED]`，
计划中的实验始终写成计划。引用最终要你自己核实。

**笔记可以用中文写吗？**
可以。笔记和讨论都可以用中文；论文正文默认输出英文，并且按论证重新组织，
不会逐句直译。

**它会改我的文件或者跑实验吗？**
引导过程中只读你的文件，不跑实验、不改文件。需要它改，请明确说出来。

**它能告诉我论文可以投了吗？**
不能替你下这个结论。没有检查过编译日志和源文件时，它只会给出 `NOT_READY` 或
`CANNOT_DETERMINE`。投不投、什么时候投，由你和指导老师或资深作者决定。
